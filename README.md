DESCRIPTION

ce  projet consiste à vréer un programme en JavaScript avec Node.js. Le 
fichier package.json contient les informations et les dépendances du projet notamment
node-emoji, tandis que index.js contient le code principal.
Le module readline permet de poser une question à l'utilisateur avec rl.question() et de récupéer sa réponse. La fonction Number() convertit la valeur saisie en nombre, puis console.log() affiche le resultat dans le terminal. Enfin, rl.close() ferme l'interface de saisie.
